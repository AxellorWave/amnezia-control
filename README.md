# amnezia-bot

Telegram-бот для раздачи конфигов **AmneziaWG** с собственного сервера Amnezia.

- Доступ по заявке: новый пользователь отправляет заявку, администратор одобряет её кнопкой.
- У каждого пользователя может быть несколько устройств (ПК, ноутбук, телефон…) со своими конфигами.
- Три формата конфига: ключ `vpn://` для AmneziaVPN / DefaultVPN, QR-код и файл `.conf`.
- Пошаговые инструкции для Android (AmneziaVPN) и iPhone (DefaultVPN) с кнопками на магазины приложений.
- Статус устройств (онлайн, трафик) таблицей прямо в чате, с кнопкой «Обновить».
- Оформление на rich-сообщениях Telegram (заголовки, таблицы, раскрывающиеся блоки) и кастомных эмодзи.
- Админ-панель: пользователи, заявки, отзыв доступа, конфиги, выпущенные в приложении AmneziaVPN, дашборд сервера.
- В конфигах вместо IP используется домен, поэтому после смены IP сервера достаточно обновить DNS-запись.

Бот работает рядом с контейнером Amnezia и управляет им через `docker exec`. Клиенты, созданные ботом, видны в приложении AmneziaVPN, а клиенты из приложения — в админке бота.

## 1. Требования

- VPS на Linux (Debian / Ubuntu) с root-доступом.
- Сервер Amnezia с протоколом **AmneziaWG**, установленный через приложение AmneziaVPN.
- Docker и Docker Compose (Docker ставится вместе с Amnezia).
- Домен или поддомен (необязательно, но очень желательно).
- Telegram-бот и токен от [@BotFather](https://t.me/BotFather).

## 2. Установка сервера Amnezia

Сервер VPN ставится из официального приложения AmneziaVPN по SSH — вручную на сервере ничего делать не нужно.

Официальная инструкция: **https://docs.amnezia.org/ru/documentation/instructions/install-vpn-on-server**

Кратко:

1. Установите приложение AmneziaVPN на компьютер или телефон.
2. Нажмите ➕ → **Self-hosted VPN**.
3. Введите IP сервера, пользователя `root` и пароль (или SSH-ключ).
4. Выберите протокол **AmneziaWG** и дождитесь окончания установки.

После установки на сервере появится Docker-контейнер Amnezia (например, `amnezia-awg2`).

## 3. Домен (рекомендуется)

Если в конфигах указан домен, то при смене IP сервера пользователям не нужно получать новые конфиги — достаточно поменять одну DNS-запись.

В DNS-панели регистратора создайте запись:

| Тип | Хост  | Значение      | TTL                 |
|-----|-------|---------------|---------------------|
| A   | `vpn` | IP сервера    | минимальный (60–300) |

Получится адрес вида `vpn.example.com`. Проверка (должен вывести IP сервера):

```bash
dig +short vpn.example.com @8.8.8.8
```

> Для нового домена делегирование может занять от нескольких часов до суток.

Если домена нет, укажите в `VPN_HOST` IP сервера — всё будет работать, но после смены IP конфиги придётся выдавать заново.

## 4. Создание Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot` → задайте имя и username. Сохраните **токен**.
2. Узнайте свой Telegram ID, например, у [@userinfobot](https://t.me/userinfobot). Это будет ID администратора.

## 5. Docker и Docker Compose

Docker уже установлен вместе с Amnezia. Проверьте, есть ли Compose:

```bash
docker --version
docker compose version
```

Если вторая команда выдаёт ошибку, установите плагин Compose:

```bash
# Ubuntu
apt update && apt install -y docker-compose-v2

# Debian
apt update && apt install -y docker-compose
```

После установки снова выполните `docker compose version`. Если пакет не найден или команда не работает — воспользуйтесь официальной инструкцией: https://docs.docker.com/compose/install/linux/

> Не переустанавливайте сам Docker поверх установленного Amnezia — это может остановить VPN.

Также понадобятся `git` и `dnsutils`:

```bash
apt install -y git dnsutils
```

## 6. Загрузка проекта на сервер

### Публичный репозиторий

```bash
git clone https://github.com/AxellorWave/amnezia-control.git /opt/amnezia-bot
cd /opt/amnezia-bot
```

### Приватный репозиторий (через deploy key)

1. Создайте на сервере ключ только для этого репозитория:

   ```bash
   ssh-keygen -t ed25519 -f ~/.ssh/amnezia_bot -N "" -C "amnezia-bot deploy"
   cat ~/.ssh/amnezia_bot.pub
   ```

2. На GitHub: репозиторий → **Settings → Deploy keys → Add deploy key**. Вставьте содержимое `amnezia_bot.pub`, галочку записи не ставьте.

3. Укажите SSH, какой ключ использовать:

   ```bash
   cat >> ~/.ssh/config <<'EOF'
   Host github-amnezia-bot
       HostName github.com
       User git
       IdentityFile ~/.ssh/amnezia_bot
       IdentitiesOnly yes
   EOF
   ```

4. Клонируйте:

   ```bash
   git clone git@github-amnezia-bot:AxellorWave/amnezia-control.git /opt/amnezia-bot
   cd /opt/amnezia-bot
   ```

## 7. Проверка контейнера Amnezia

Имена контейнера, файлов и утилит зависят от версии Amnezia. Проверьте их:

```bash
# имя контейнера (ищите amnezia-awg2 или amnezia-awg)
docker ps --format '{{.Names}}'

# файлы конфигурации (подставьте своё имя контейнера)
docker exec amnezia-awg2 sh -c 'ls /opt/amnezia/*/'

# какие утилиты есть внутри
docker exec amnezia-awg2 sh -c 'which wg awg wg-quick awg-quick'
```

Типичные значения:

| Версия           | CONTAINER      | CONF_DIR            | IFACE  | WG_BIN | WG_QUICK_BIN |
|------------------|----------------|---------------------|--------|--------|--------------|
| AmneziaWG 2      | `amnezia-awg2` | `/opt/amnezia/awg`  | `awg0` | `awg`  | `awg-quick`  |
| AmneziaWG (старая) | `amnezia-awg`  | `/opt/amnezia/awg`  | `wg0`  | `wg`   | `wg-quick`   |

`IFACE` — это имя файла конфигурации без `.conf` (`awg0.conf` → `awg0`).

## 8. Настройка .env

```bash
cp .env.example .env
nano .env
```

| Переменная      | Обязательна | Описание |
|-----------------|:-----------:|----------|
| `BOT_TOKEN`     | да | Токен от @BotFather |
| `ADMIN_IDS`     | да | Telegram ID администраторов через запятую |
| `VPN_HOST`      | да | Домен (`vpn.example.com`) или IP сервера |
| `CONTAINER`     |    | Имя контейнера Amnezia (по умолчанию `amnezia-awg2`) |
| `CONF_DIR`      |    | Папка конфигов внутри контейнера (`/opt/amnezia/awg`) |
| `IFACE`         |    | Имя интерфейса (`awg0`) |
| `WG_BIN`        |    | Утилита управления (`awg`) |
| `WG_QUICK_BIN`  |    | Утилита quick (`awg-quick`) |
| `SERVER_NAME`   |    | Имя сервера в приложении AmneziaVPN для ключа `vpn://` (`vpn`) |
| `DNS1`, `DNS2`  |    | DNS-серверы в конфигах клиентов (`1.1.1.1`, `1.0.0.1`) |
| `MTU`           |    | MTU для ключа `vpn://` (`1280`) |
| `MAX_DEVICES`   |    | Лимит устройств на пользователя (`5`, у админов без лимита) |
| `KEEPALIVE`     |    | PersistentKeepalive; пусто — как в приложении (`25-35` для AWG 2) |
| `CUSTOM_EMOJI`  |    | Кастомные эмодзи в сообщениях и на кнопках (`1`); `0` — обычные эмодзи |

> Кастомные эмодзи работают, только если у владельца бота есть **Telegram Premium**. Без него бот сам переключится на обычные эмодзи, но лучше сразу указать `CUSTOM_EMOJI=0`.

Сохранение в `nano`: `Ctrl+O`, `Enter`, выход — `Ctrl+X`.

## 9. Запуск

Перед первым запуском сохраните конфиг сервера:

```bash
docker exec amnezia-awg2 cat /opt/amnezia/awg/awg0.conf > ~/awg0.conf.bak
```

Запуск:

```bash
cd /opt/amnezia-bot
docker compose up -d --build
docker compose logs -f
```

В логе должна появиться строка вида:

```
Сервер: 10.8.1.0/24, порт 33667, AWG2=True, параметры: Jc, Jmin, ...
```

Выход из лога — `Ctrl+C` (бот продолжит работать). Откройте бота в Telegram и отправьте `/start`.

Полезные команды:

```bash
docker compose ps           # статус
docker compose restart      # перезапуск
docker compose down         # остановка
docker compose logs --tail 100
```

## 10. Обновление

```bash
cd /opt/amnezia-bot
git pull
docker compose up -d --build
```

База пользователей хранится в `./data` и при обновлении не теряется.

## 11. Использование

### Пользователь

- `/start` → **Отправить заявку** → ждёт одобрения.
- **📱 Мои устройства** — список устройств (🟢 — сейчас подключено). В карточке устройства:
  - 🔑 ключ `vpn://` (для AmneziaVPN и DefaultVPN),
  - 📷 QR-код,
  - 📄 файл `.conf`,
  - 🗑 удаление.
- **➕ Добавить устройство** — бот спросит название (Телефон, Ноутбук…).
- **📖 Как подключиться** — инструкции для Android и iPhone.
- **📊 Статус** — таблица устройств с онлайном и трафиком, кнопка «Обновить».

### Администратор

Кнопка **👑 Админка** в меню или команда `/admin`:

- **👥 Пользователи** — карточка пользователя: устройства, удаление, отзыв доступа, повторное разрешение заявки, личный лимит устройств.
  - **✏️ Лимит устройств** — бот попросит число от 0 до 100; «-» или кнопка «Сбросить» возвращает общий `MAX_DEVICES`. Если устройств уже больше нового лимита, они не удаляются — просто нельзя добавить новые.
- **⏳ Заявки** — одобрение и отклонение.
- **🚫 Отклонённые** — отклонённые заявки и отозванный доступ. В карточке кнопка **✅ Вернуть доступ** сразу одобряет пользователя и присылает ему то же уведомление, что и при обычном одобрении.
- **📲 Из приложения** — конфиги, выпущенные в AmneziaVPN, с возможностью удаления.
- **📊 Дашборд** — таблица всех клиентов сервера.

В списке пользователей, карточке и уведомлениях о заявках и новых устройствах видно имя (ссылка на профиль), @username (ссылка) и Telegram ID.

О новых заявках и новых устройствах бот сообщает администраторам.

## 12. Смена IP сервера

Если в `VPN_HOST` указан домен:

1. Смените IP в панели хостинга.
2. Обновите значение A-записи в DNS на новый IP.
3. Пользователи просто переподключаются — конфиги остаются прежними.

Проверить, какой IP видит мир: `curl -s ifconfig.me`.

## 13. Резервные копии

Сохраняйте:

- `/opt/amnezia-bot/.env` — настройки и токен;
- `/opt/amnezia-bot/data/` — база пользователей и устройств;
- конфиг сервера Amnezia:

  ```bash
  docker exec amnezia-awg2 cat /opt/amnezia/awg/awg0.conf > ~/awg0.conf.bak
  docker exec amnezia-awg2 cat /opt/amnezia/awg/clientsTable > ~/clientsTable.bak
  ```

## 14. Решение проблем

**Бот не запускается, в логе `docker exec failed`**
Проверьте `CONTAINER`, `CONF_DIR`, `IFACE` в `.env` (раздел 7).

**`docker compose: command not found`**
Установите Compose (раздел 5).

**Конфиг выдаётся, но не подключается**
- Проверьте домен: `dig +short vpn.example.com @8.8.8.8` должен вернуть IP сервера.
- Проверьте, что порт AmneziaWG (UDP) открыт в фаерволе хостинга.
- Сравните `docker exec amnezia-awg2 awg show` — появляется ли handshake у клиента.

**Сообщения приходят без форматирования**
Бот использует rich-сообщения Telegram. Если они недоступны, бот автоматически присылает обычное сообщение. Обновите приложение Telegram.

**Вместо красивых иконок — обычные эмодзи**
Кастомные эмодзи требуют Telegram Premium у владельца бота. Без него бот показывает обычные эмодзи — это нормально. Чтобы отключить их явно, укажите `CUSTOM_EMOJI=0` в `.env` и перезапустите бота.

**Безопасность**
Бот получает доступ к Docker через `/var/run/docker.sock`, то есть фактически root-доступ к серверу. Не передавайте никому `.env` и токен бота.
